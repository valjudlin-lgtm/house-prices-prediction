# 🏠 House Prices Prediction

## 🎯 Objectif
Prédire les prix des maisons à partir de données immobilières (Kaggle).

## 📊 Données
Dataset Kaggle House Prices

## ⚙️ Modèles utilisés
- XGBoost
- LightGBM
- CatBoost

## 🔧 Méthodes
- Feature engineering
- Nettoyage des données
- Optimisation des hyperparamètres

## 🏆 Résultat
Top 3% sur Kaggle
