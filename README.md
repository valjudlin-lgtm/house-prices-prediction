# 🏠 House Prices Prediction

## 🎯 Objectif
Ce projet vise à prédire le prix de maisons à partir de caractéristiques immobilières, dans le cadre d’une compétition Kaggle.

## 📊 Données
Dataset : Kaggle House Prices  
Variables : surface, localisation, qualité, année de construction, etc.

## ⚙️ Méthodologie

- Nettoyage des données
- Feature engineering (création de variables pertinentes)
- Gestion des valeurs manquantes
- Encodage des variables catégorielles

## 🤖 Modèles utilisés

- LightGBM
- XGBoost
- CatBoost

## 🔧 Optimisation

- Tuning des hyperparamètres
- Validation croisée
- Comparaison des performances

## Résultats
- Score Kaggle (RMSE sur le log du prix) :0.11976 – top 3 % du classement

## Exécution
1. Télécharger les données sur [Kaggle](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)
2. Installer les dépendances : `pip install -r requirements.txt`
3. Lancer le notebook `prediction-using-lightgbm-xgboost-catboost.ipynb`
